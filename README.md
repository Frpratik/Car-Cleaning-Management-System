# 🚗 AuraCar OS — Precision Car Care Platform for Gated Communities

> **The Operating System for Recurring Residential Vehicle Maintenance.**

AuraCar OS turns car maintenance into an invisible, recurring morning utility for urban residents living in gated societies and apartment complexes. 

---

## 🌟 Core Pillars

1. **Hyper-Local Society Density:** Built around the physical hierarchy of **Society $\rightarrow$ Tower $\rightarrow$ Level $\rightarrow$ Parking Slot $\rightarrow$ Vehicle**. Providers walk in strictly ordered sequential routes in basements, servicing up to 28 cars before 8:00 AM with near-zero transit overhead.
2. **Scratch-Free Waterless Maintenance:** Standardized color-coded microfiber protocol (Green for body, Yellow for windshield/glass, Black for tyres) paired with eco-friendly lubricated formulas approved by Resident Welfare Associations (RWAs).
3. **Cryptographic Verification Proof:** Every completed job includes before/after high-resolution photos stamped with timestamp and slot hash verification.
4. **Offline-First Resilience:** Underground basements with zero mobile reception cache photo captures in local IndexedDB/memory queues and auto-sync upon emerging into cellular coverage.

---

## 🏗️ Architecture & Technology Stack

* **Frontend:** React 18+ with TypeScript, Vite, custom CSS token design system (Anti-AI obsidian theme).
* **State Management:** Reactive local store with high-fidelity Indian seed data (Prestige Lakeside Habitat, Sobha Dream Acres, Godrej Eternity).
* **Database Schema:** PostgreSQL 16 with Prisma ORM ([`prisma/schema.prisma`](prisma/schema.prisma)).
* **Scheduling Engine:** Dynamic forward-calendar matrix with pro-rated vacation pause billing protection.
* **Payments:** Razorpay Subscriptions / UPI Autopay reconciliation.

## 📱 Three Platform Experiences

### 1. 🚗 Customer Experience
* Active Vehicle & Designated Basement Slot card.
* Today's Service window, assigned dedicated specialist, and inclusions.
* Interactive Before/After Split Viewer with slider.
* 14-Day Calendar Matrix with Scheduled, Cleaner Rest, and Vacation Paused days.
* 1-Tap Vacation Pause Planner with automatic renewal date extension.
* Rating modal (1–5 stars) & Dispute / Complaint reporting.
* Invoices & Receipts drawer.

### 2. 🧽 Provider Field App
* Step-by-step spatial route navigator sorted by walking sequence.
* High-contrast outdoor mode with large touch targets.
* In-app camera viewfinder simulator with cryptographic watermark stamp.
* Basement offline queue with background sync flusher.
* Standard 3-step quality checklist and exception reporting.

### 3. 🛡️ Operations Command Center
* Live morning manifest progress, fleet completion rate, and cleaner attendance.
* Society density fleet monitor across active clusters.
* 1-Click Cleaner Re-assignment for emergency morning coverage.
* Customer Disputes & Claims Queue with side-by-side photo audit.
* Finance & Subscription Billing ledger with 42.4% net margin tracking.

## 🚀 Quickstart & Local Development

```bash
# Clone the repository
git clone https://github.com/Frpratik/Car-Cleaning-Management-System.git
cd CCA

# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production
npm run build
```

Open **`http://localhost:3000`** in your browser.
